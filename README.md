# Data-Cleaning-Power-Query
# 🧹 Data Cleaning with Power Query

## About the Project
This project demonstrates an automated data cleaning pipeline in Excel. I took a raw dataset with messy dates and duplicate records and used Power Query to clean it.

## Skills Used
* Microsoft Excel
* Power Query Editor
* Data Cleaning & Preparation
* Deduplication

## What Was Done
* Fixed incorrect date formats to standard Date types.
* Removed nearly 5,000 duplicate records, reducing the dataset from 9,800 rows to 4,923 clean rows.
